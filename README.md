# 🛡️ SOC & Blue Team Investigations Archive

Welcome to my continuously updated repository for Security Operations Center (SOC) and Blue Team writeups. This project serves as a growing knowledge base documenting my hands-on investigations into various cyber threats, with a strong focus on defensive security auditing, digital forensics, and incident response (DFIR).

This is a **living repository**. I regularly add new challenge solutions and investigative lab breakdowns—primarily from [CyberDefenders](https://cyberdefenders.org/) and other practical defense platforms—as I continually refine my analytical methodologies.

### 🔍 Core Focus Areas
As this repository expands, the writeups span across multiple critical DFIR domains, including:
*   **Network Traffic Analysis:** Investigating network packets (PCAPs) using tools like Wireshark, Tshark, and Suricata to identify malicious communications and data exfiltration.
*   **Endpoint & Memory Forensics:** Analyzing memory dumps, system logs, and artifacts to track lateral movement, persistence mechanisms, and hidden payloads.
*   **Malware Analysis & Threat Hunting:** Deep dives into the behavior of infostealers, trojans, and targeted attacks, extracting vital Indicators of Compromise (IOCs).
*   **Incident Response:** Correlating multi-source logs to construct accurate attack timelines and develop effective defensive incident management playbooks.

### 🚀 Status: Actively Updating
I am constantly working on new scenarios. Each directory inside represents a complete, step-by-step analytical process of a specific security incident. Feel free to explore the investigations!
